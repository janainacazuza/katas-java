## How to run an exercise

From the repository root, run any exercise with one command (JDK 25, no build tool):

    java m00-how-java-runs/01-hello-asymptora/HelloAsymptora.java

## Repository structure

One folder per module, and one numbered folder per exercise inside it.
Folders use kebab-case, Java files use PascalCase.

| Module | Folder | What it covers |
|---|---|---|
| M0 | `m00-how-java-runs` | how a Java program exists and runs |
